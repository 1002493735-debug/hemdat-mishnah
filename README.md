# לומדים יחד – משלימים יחד
ממ״ד חמדת השקד – מבשרת ציון

משחק משניות עם התקדמות בית־ספרית משותפת וכרטיסי הגרלה אישיים.

**גרסת פיתוח. הקוד נכתב; בדיקות ופריסה עדיין בתהליך. אין עדיין אתר חי מאומת.**

## מה כלול
- מבנה של 149 משניות ב־17 פרקים, 6 משניות מוכנות ו־143 מקומות שמורים.
- ראש השנה: 9, 9, 8, 9 (35); יומא: 8, 7, 11, 6, 7, 8, 5, 9 (61); סוכה: 11, 9, 15, 10, 8 (53).
- כניסה בקוד בית ספר ואז בחירת כיתה ושם. מנהל עם סיסמה נפרדת.
- לימוד אקראי, מפת מסכתות מלאה, שאלה אקראית וערבוב אפשרויות בצד השרת.
- נעילה זמנית, השהיה הנשמרת בשרת והשלמה אטומית עם כרטיס יחיד.
- לוח כרטיסים לפי שמות וכיתות, תרומת כיתות ופעילות אחרונה אנונימית.
- בונוס אוטומטי לאחר סיום הסבב הראשון, היסטוריה וסבבים נוספים.
- ניהול, תיקונים מתועדים, ביטול השלמה, ייבוא JSON/CSV וייצוא CSV להגרלה.
- סכמה, בדיקות, Docker ותצורת אירוח עם דיסק מתמשך.
