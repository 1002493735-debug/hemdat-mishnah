# לומדים יחד – משלימים יחד
ממ״ד חמדת השקד – מבשרת ציון

משחק לימוד משניות עם התקדמות משותפת לבית הספר וכרטיסי הגרלה אישיים.

## כלול
- 149 משניות מנוקדות, 298 שאלות, רמזים ומקורות מהמאגר המתוקן שסופק.
- סוכה 53, ראש השנה 35, יומא 61, ב־17 פרקים.
- מפת מסכתות, לימוד אקראי, נעילה, השהיה, ערבוב שאלות ותשובות והשלמה אטומית.
- כרטיסים אישיים, תרומות כיתתיות, בונוס אוטומטי והיסטוריית סבבים.
- ניהול, ייבוא Excel/CSV/JSON, תיקון כרטיסים וביטול השלמות, ייצוא וגיבוי ושחזור.
- שלושה איורים מקוריים, עברית ו־RTL, נייד, מקלדת והפחתת אנימציה.

## הטכנולוגיה הפעילה
הממשק ב־static, ה־API ב־worker. האתר מתארח ב־Sites באמצעות Cloudflare Worker ובסיס D1 מרכזי. הסכמה ב־db/schema.ts והמיגרציות ב־drizzle. תוכן המשניות נפרד בקובץ data/content.json.

אב־הטיפוס Flask הקודם נשמר ב־server.py כחלופת אירוח עצמית. האתר הפעיל משתמש ב־Worker. ייבוא Excel וגיבוי JSON הם חלק מה־Worker.

## התקנה
Node 22.12 ומעלה:
```sh
npm ci
npm run build
npm test
npm run dev
```
הפיתוח המקומי בפורט 4173. פרטי הבדיקה המקומיים ב־scripts/dev.mjs אינם סודות של האתר החי.
