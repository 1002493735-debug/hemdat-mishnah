ההעתקה כאן משנה את חלוקת השורות, סימני הפיסוק במקומות מסוימים ואיות מנוקד נקודתי. לא הועתקו פירושים. השאלות נכתבו במיוחד להדגמה.
יש להעביר את הדוגמאות לבדיקת צוות ההוראה לפני הפצה לתלמידים.
